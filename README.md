## Run locally

```bash
git clone https://github.com/Still-not-found/My_Portfolio.git
cd My_Portfolio
npm install
npm run dev
```

Then open the URL Vite prints (default `http://localhost:5180`).

```bash
npm run build    # production build
npm run preview  # preview the build
```

**Needs:** Node.js 20+
